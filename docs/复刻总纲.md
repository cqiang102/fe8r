> 第 106 轮由用户重定义目标：**先完整复刻整个项目**，

## 一、目标判读（三处要说清）

1. **结合日美两版**：
   * 两版**同名不同值**是实测过的（`PrologueGradoRoyals` 第 2 条：日版 `y=11`、美版 `y=7`）；
   * 所以规则是：**日版优先**；日版 **masked / 未 carve / 读不到**时**用美版**，
     并且**逐处标注来源**（`PORT OF:` 或注释里写清"来自美版"）。
   * 量化依据（第 100 轮实测 `layout/us_jp_funcmap.tsv`，7734 个符号）：
     `exact` **5996（77%）**、`masked` **1721（22%）**、`fixup` 17。
     卡住我们的 `ProcScr_*`（203/205 masked）、M4A 音频引擎（16/44）**正好在 masked 里**
     ⇒ 美版能直接提供可读实现。
2. **不是 GBA，是 macOS app**：
   * 仓库**已经**是这个形态：`macos/Runner.xcodeproj` 在，
     `tools/verify/scenario.sh` 构建 `build/macos/Build/Products/Release/fe8r.app`；
   * 所以"表现层"用 Flutter/Flame **重写**（不是软件 GBA 模拟）；
     规则层逐位对齐源码（`lib/core`，R1–R7 强制）。
3. **用现代 Dart 写法**：`records` / 模式匹配 `switch` / `sealed class` /
   `final` 局部变量 / 扩展方法 —— 已经在用（例如 `({List<int> words, EventScript script})`）。

## 四、核对"到底做没做"的**唯一可靠办法**

```bash
# 1) 先 grep 代码（别再信文档）
grep -rn "<关键词>" lib/ --include=*.dart | head
# 2) 再看门禁自己的"尚未实现"段（它是活的）
"$HOME/fvm/versions/<ver>/bin/cache/dart-sdk/bin/dart" run tools/verify/run_all.dart | sed -n '/尚未实现/,$p'
# 3) 最强的判据是端到端（默认不在门禁里，要 --e2e）
"$HOME/fvm/versions/<ver>/bin/cache/dart-sdk/bin/dart" run tools/verify/run_all.dart --e2e
```
