# 菜单盘点 —— **原版有好几种，不能强行复用**

> 用户提醒：「原版也有几种不同的菜单，不能强行复用，先读源码再做」
>
> **他是对的。** 我上一轮抽了一个通用的「圆角列表框」，
> 又把它当成"Flame 的做法"到处用 —— 那是**我的设计**，不是原版的。

## 一、主菜单（`src/savedraw.c:184-219`）

```c
void SaveDraw_DrawMainMenuOptions(struct SaveDrawProc * proc)
{
    int xOffset = unk_2f + unk_46;
    if (xOffset < 220) {
        int y = 68 - ((int)(unk_31 * 25) >> 1);     // ★ 68 - count*25/2
        if (y < 2) y = 2;

        for (i = 0; i < unk_31; i++) {
            int spriteIdx = BitfileToIndex(SaveMenuGetBitfile(main_options, i));
            if (i == main_select)
                SaveDraw_DrawMainMenuOption(proc, 48 - xOffset, y + i * 25, spriteIdx, 1, 4);
            else
                SaveDraw_DrawMainMenuOption(proc, 48 - xOffset, y + i * 25, spriteIdx, 6, 4);
        }
        if (jump_label == PL_SAVEMENU_MAIN_LOOP)
            SaveDraw_SetCursorBox(0, 28, y + main_select * 25, proc);
    }
}
```

| 项 | 值 |
|---|---|
| 起点 X | **48** |
| 居中 | `y = 68 - count * 25 / 2`，下限 2 |
| 行距 | **25** |
| 精灵表 | `SpriteArray_SavemenuData_1[]` |
| 光标框 | `jump_label == PL_SAVEMENU_MAIN_LOOP` 时，位置 `(28-2, y-12)` |

每项两个精灵（`savedraw.c:99-103`）：

```c
PutSpriteExt(4, OAM1_X(x),     y,     Sprite_Savedraw_0, OAM2_PAL(palIdA));  // 图标
```

## 四·五、地图菜单（玩家阶段按 START）★ **第五种独立布局**

出处：`src/playerphase_0801C5A8.c:105-160`（打开）+
`src/exact_0804f924.c:43-55`（分侧）+ `src/StartMenuCore.c:30-98`（筛选/行距/高度）

```c

StartOrphanMenuAdjusted(&gMapMenuDef, gBmSt.cursorTarget.x - gBmSt.camera.x, 1, 0x17);
```

| 项 | 值 | 出处 |
|---|---|---|
| 面板 rect | `x=1 / 0x17`、`y=2`、`w=6`、`h=0`（按行数算）| `frontier_df4_uistuff.c:12403-12412` |
| 分侧阈值 | 光标**屏幕像素** `< 120` → 贴右（0x17），否则贴左（1）| `exact_0804f924.c:49` |
| 行距 | **2 个 UI 图块（16px）** | `StartMenuCore.c:71` |
| 文字内缩 | 面板左边缘 + **1 个 UI 图块** | `StartMenuCore.c:64,68` |

**三条可见性规则**（会直接改变画出来的行数）：

| 条目 | 规则 | 出处 |
|---|---|---|
| 戦績 | `GetBattleMapKind() != DUNGEON` → **`MENU_NOTSHOWN`** | `MapMenu_IsRecordsCommandAvailable.c:53` |
| 退却 | `GetBattleMapKind() == STORY` → **`MENU_NOTSHOWN`** | `bmmenu_08024C7C.c:62` |
| 中断 | `PLAY_FLAG_TUTORIAL` → **`MENU_DISABLED`**（灰着、按下去只弹消息 `0x7E2`，**菜单不关**）| `masked_0802257c.c:63` + `MapMenu_SuspendCommand.c:51-54` |

→ `Proc_EndEach(gProcScr_PlayerPhase)`）—— **不是 NULL**。

### 状态（四类口径）

* **机器验证**：条目顺序/overrideId/color/消息号、行距 2、`h = 2*行数+2`、
  `MENU_NOTSHOWN` 不占行、教学下「中断」变灰且不关菜单 ——
  `test/core/map_menu_test.dart`（14 条，且**都做过变异证伪**）；
  端到端 `tools/verify/scenario.sh mapmenu`（23 条判据）+ `menuend`（10 条）。
* **抽查过**：`GetBattleMapKind()` 在序章/第 1 章/C00 是 `story`
  （日版本体 `0x080C1E74` **没有 carve**，见 `lib/core/flow/battle_map_kind.dart`）；
  辞书锁定 = 非教学模式（序章那句 `ASMC(BmGuideTextSetAllGreen)` 的 `BNE` 条件）；
  `PLAY_FLAG_TUTORIAL == 0`（这条链上没人置它 —— 一处 `grep` 的否定结论）。

## 五、结论与做法

**原版至少这四种，各自布局不同：**

| | 布局 | 呈现 |
|---|---|---|
| 主菜单 | X=48、居中 `*25/2`、行距 25 | 图标 + 标签 + 括弧 |
| 附加内容 | X=268、居中 `*12`、行距 25/21 | 图标 + 标签 + 括弧 |
| 难度 | 边框 + 右侧说明文字 | TSA 边框 + 文本 + 精灵 |
| **地图菜单** | **贴左/贴右由光标屏幕像素决定、行距 2 个 UI 图块、`h = 2*行数+2`** | **BG 窗口 + 文字（无图标）** |
| 战斗行动 | 另一套子系统 | — |

**做法**：
* **一处菜单一个组件**，各自的 X/居中公式/行距/精灵表**照各自的源码**
* 只有真正相同的部分（括弧指示器的形状与浮动机制）才共用
* 标签文字取不到图块时用占位，但**布局数值必须来自源码**

> 我上一轮的错误：把"用一个组件"当成了目标。
> **共用是结果，不是目标** —— 四处不同却共用一个组件，那是把差异抹掉。
