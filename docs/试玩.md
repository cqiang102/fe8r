# 试玩说明（给我自己人测的版本）

## 怎么起

```bash
./tools/play.sh            # 构建（需要时）+ 启动；关窗口即退出
```

想同时让 AI/脚本接管（可选）：`FE8R_CTL=41999 ./tools/play.sh`，
然后 `dart run tools/verify/ctl.dart '{"cmd":"state"}'` 读状态。

## 按键（与 `lib/game/fe8_game.dart` 的 `onKeyEvent` 一一对应）

| 键 | 作用 |
|---|---|
| 方向键 / WASD | 移动光标 |
| **Z / 空格** | 确认（原作的 A 键） |
| **X / ESC** | 取消（原作的 B 键） |
| **回车** | **START** —— 玩家阶段打开地图菜单；剧情里**跳过整段**（`src/event_0800D110.c:27`）|
| **E** | 直接结束回合（**开发捷径，原作没有**；原作只能走 START→菜单→終了）|
| **C** | 触发剧情演示（开发用）|
| **H** | 显示 / 收起按键说明 |

## 能玩到哪

1. 开机：健康警告 → 标题（不按键 815 帧会播职业介绍）→ START → 主菜单
2. 新游戏 → 难度（新手/普通/困难）→ 存档槽（**不写盘**，M9 未做）
3. **序章**：三段过场（王座厅 → 王城 → 游玩地图），剧情、放敌、给细剑
4. 打：移动范围、选中、攻击、反击、乱数、回合流转（两种结束方式）
5. 打死奥尼尔 → 序章结束剧情 → **第 1 章**，第 1 章也有开场剧情
6. START 打开地图菜单（8 条里「終了」可用）

## 最想要的反馈（按价值排）

1. **手感/节奏**：光标移动、移动范围、选中→待机/攻击这条链顺不顺；哪里"按了没反应"（除了上表那些）。
2. **画面**：单位/光标/地形/面板的位置与大小哪里别扭（截图 + 当时在第几回合最好）。
3. **对不上原作的地方**：你在意的任何一处"原作不是这样"。
4. **卡住**：走到某一步走不下去 —— 请附上屏幕底部那行字（有状态）或截图。
