## 没做成的（挡住目标的）

### ① 战斗数值仍跑在**演示数据**上 —— 这是最直接的拦路虎

```dart
CombatProfile _profileFor(MapUnit u) {
  if (u.factionBit == Faction.red) {
    final isArcher = u.id == 0x82;        // ← 演示单位的 id
    return CombatProfile(classId: isArcher ? 0x1B : 0x2A, ...);
  }
  ...
}
_items = _demoItems();                     // ← 武器数据也是演示的
```

**我载入了真实的 `classId` / `charIndex` / 等级 / 道具，但战斗没用它们。**
后果：奥尼尔打不掉（`C63:20` 一直满血），伤害全落在艾莉卡身上。

**要做**：`_profileFor` 从 `classId` + 职业表（`classes.json`）+
道具表（`items.json`）+ 角色基础值建 profile。

### ② 战斗动画**完全没有** —— 一整个子系统

原版按攻击会切到侧视的 **banim** 场景。我这里只有数字和战报文字。

素材**是有的**：`third_party/fireemblem8j/graphics/banim/` 有 **681 项**
（`banim_<职业><性别>_<武器>.agbpal` 调色板 + `banim_..._sheet_N.png` 帧）。

缺的是：
* **动画脚本**（帧序、时序、命中帧、音效）—— `src/data/banim_battleparse/`
* **侧视战场**（背景、站位平台）
* **血条 / 伤害数字 / 武器特效**

**这是 M 级别的工程量，不是"补个动画"。**

### ③ 别的次要项
* 地图历史只在"载入单位"时刷新（HUD 显示时机不对）
* `Event_TextWithBG` 等 16 个脚本仍未解出
* 存档系统、战斗胜负以外的章节逻辑

## 一句话

**"序章能玩"是真的**（走位、选人、交战、结算都通），
**"能打通到第 1 章"还没做到** —— 卡在战斗数值仍是演示数据，
以及战斗动画这个子系统根本没开始。
