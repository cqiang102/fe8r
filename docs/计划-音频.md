## 三、表现（macOS app 怎么出声）

**离线渲染 + 播放文件**（推荐，且符合"规则 1:1、表现自己实现"）：

1. 用 Dart 写一个**照 M4A 语义**的合成器（读 MIDI 的音符/时值 + 音色组 + 采样）；
2. 管线里把每首曲子渲染成 `.wav`（确定性、可复现、可抽查）；
3. app 侧只负责**播放文件**（Flutter/macOS 的音频播放，不需要运行时合成）。

⚠️ 为什么不用"运行时合成"：那需要 FFI/平台插件，且**无法在 CI 里判据**；
离线渲染的产物可以**逐字节比对**、也可以抽听抽查。

## 四、判据（每一段都要有）

* 数据：条数 + **正向抽查真值**（例：`music_player_table` 第 n 项指向哪个 voicegroup ✓）；
* 规则：合成器的**事件时轴**逐条与 MIDI 对齐（音符数/时刻/时长）；
* 表现：渲染出的 `.wav` **时长**与该曲 MIDI 的总时长一致（±1 帧），
  且**非静音**（RMS > 阈值）——这条能抓到"文件在、但是空的"。

## 五、不许做的事（本规矩的直接推论）

* **不许**只做"状态层"就宣称音频接上了（现在的状态就属于这种，已标注未完成）；
* **不许**用别的音频资产冒充 GBA 音色（要就照音色组 + 采样做，要就明说没有）；
* **不许**在没有"事件时轴对齐"判据的情况下就说"能放"。
