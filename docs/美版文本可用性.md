# 有没有现成的译文？—— 查证结果

> 用户让我查「源码里是否已经有翻译好的」。
> **结论：日版仓库里没有译文，但美版（官方英文）全文可以拿到。**

## 一、日版仓库里**没有**任何译文（已彻底确认）

| | |
|---|---|
| `texts/` | 只有 `jp_texts.txt` / `jp_textdefs.txt` / `jp_huffman_tiebreaks.txt` |
| `scripts/texttools/` | `huffman.py` / `msg_jp.py` / `textdecoder.py` —— **日文专用** |
| 中文 / 英文文本 | **零** |

`docs/asset_fe8u_diff.md` 也指出：**美版的文本在 711 个 JP-unique 资产里**
—— 也就是说**这个仓库是日版（fe8j），不含美版内容**。

## 二、★ 但美版反编译仓库是**公开的**，英文全文可以下载

    https://github.com/FireEmblemUniverse/fireemblem8u
    https://raw.githubusercontent.com/FireEmblemUniverse/fireemblem8u/master/texts/texts.txt

实测可下：**1,469,193 字节，3403 条消息**。
（另有 `texts/textdefs.txt`，4,648 字节，控制码定义。）

已存到 `tools/i18n/ref/`。

## 三、日版仓库里还有一张 `layout/msg_map.tsv`（US ↔ JP 对照）

    2770 条，格式 `us_id	jp_id	source`
    source 分布：interp 2325、auto:shifted 338、extrap 98、seed 8

**看起来正是我需要的。但实测对不上。**

## 四、★ 实测：ID **不对齐**

三个具体反例：

| | 日版 | 美版 |
|---|---|---|
| `0x8C3` | 王座厅（士兵报告城门被破）| `"Your hands are full."` |
| `0x8ED` | 艾莉卡说服赛特去救米乌兰城 | 关于【圣石】的旁白 |
| `0x8CE` | 越过桥就是弗雷利亚领 | `"Your storage is full, too."` |

再用**控制码签名**验证（两版共用引擎控制码）：

    0x8C3:  JP 28 个 [OpenMidLeft][LoadFace][$0152]...   US 只有 1 个 [A]
    0x8ED:  JP 47 个                                       US 15 个

**美版 dump 似乎剥离了立绘/表情控制码**，而文本顺序也不一致。

**所以 `msg_map.tsv` 的"恒等"假设在我测的这些区间不成立。**

## 五、那这份英文有什么用

**有，而且价值不小 —— 但用法是"参照"，不是"机械替换"：**

1. **术语校准**：官方译名（Sacred Stones / Renais / Grado / Frelia /
   Eirika / Ephraim / Seth / Valter …）可以直接对到中文
2. **语义核对**：日文有歧义时，查官方英文那句话怎么理解
3. **原文查找**：按特征词搜索，能定位到对应段落
   （即使 id 不对齐，**内容是对应的**）

**不能做的**：按 id 直接取英文当译文 —— 会大面积错位。

## 六、结论

* **没有"翻译好的中文"可用** —— 译文必须做
* **英语官方文本可用**，作为**质量参照**（这才是它最大的价值）
* 若将来要做**精确对齐**，需要按内容/控制码做一次匹配 ——
  那是独立的一块工作，且 `msg_map.tsv` 不能直接信任
