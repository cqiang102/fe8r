`src/titlescreen_080CB2A0.c:33-52`：

```c
void Title_IDLE(struct TitleScreenProc * proc)
{
    proc->timer_idle++;
    if (gKeyStatusPtr->newKeys & (A_BUTTON | START_BUTTON)) {
        PlaySoundEffect(SONG_6D);
        SetNextGameActionId(GAME_ACTION_EVENT_RETURN);   // → 主菜单
        Proc_Break(proc);
    } else {
        if (proc->timer_idle == 815) {                    // ← **正好 815 帧**
            SetNextGameActionId(GAME_ACTION_CLASS_REEL); // → 职业介绍
            Proc_Break(proc);
        }
    }
}
```

**815 帧 @60fps ≈ 13.6 秒**。这就是用户说的"不按开始键过一会会播职业介绍"。

`GAME_ACTION_*` 见 `include/types.h:337-351`：
`GAME_ACTION_EVENT_RETURN = 0`、`GAME_ACTION_CLASS_REEL = 1`。
