# 缺失的事件脚本（41 个）—— 它们都在 `.s` 里是裸字节

## 现象

HUD 的 `缺N` 记的是 `Scene.missing`（`call` 不到的目标）。
序章的 `BeginningScene` 会 `CALL` 这些脚本，而它们**全都没有被生成**：

    EventScr_Prologue_ONeillSpawn        <- ★ 放敌人（奥尼尔）
    EventScr_Prologue_EirikaAttacked
    EventScr_Prologue_ExecTut
    EventScr_Prologue_Tutorial0/1/2/4/5/A/B/C
    EventScr_Prologue_9EF828
    EventScr_LoadReinforce / LoadReinforceHardMode / LoadUnitForTutorial
    EventScr_ChangeAIinQueue
    EventScr_SetBackground / TextShowWithFadeIn / UnTriggerIfNotUnit
    （共 41 个）

## 为什么缺

`gen_scene_dart.py` 只解析 **C 文件里的宏形式**：

```c
CONST_DATA EventListScr EventScr_X[] = {
    LOAD1(1, UnitDef_Event_Y)
    ENUN
    ...
};
```

而这 41 个脚本在日版仓库里**只以裸 `.4byte` 存在**：

```asm
	.global EventScr_Prologue_ONeillSpawn
EventScr_Prologue_ONeillSpawn:
	.4byte 0x00012C40
	.4byte UnitDef_Event_PrologueEnemy
	.4byte 0x00003020
	.4byte 0x00683B21
	...
```

**和 `UnitDef_Event_PrologueMessager`、`UnitDef_Event_PrologueGradoRoyals`
是同一类问题** —— 那些是用 `parse_unit_defs_asm.py` 解决的，
**事件脚本也需要一个对应的 `parse_event_scripts_asm.py`**。

## ★ 已经能对上编码（用美版的 C 当规格）

美版的 `ONeillSpawn`（`src/events/prologue-eventscript.h:224`）：

```c
LOAD1(1, UnitDef_Event_PrologueEnemy)     // 2 字：命令 + 表指针
ENUN
FlashCursor(CHARACTER_ONEILL, 60)
MUSC(SONG_SHADOW_OF_THE_ENEMY)
Text(0x910)
ENUF(EVFLAG_BGM_CHANGE)
ENDA
```

日版字节逐条对：

| 字节 | 解码 |
|---|---|
| `0x00012C40` | **LOAD1**（cmd `0x40`，arg `0x0001` = 组 1）|
| `UnitDef_Event_PrologueEnemy` | LOAD1 的表指针 |
| `0x00683B21` | **FlashCursor**（cmd `0x21`），`0x68` = **104 = CHARACTER_ONEILL** ✓ |
| `0x00000120` | **ENDA**（cmd `0x20`） |

**`0x00683B21` 里的 `0x68 = 104` 与 `CHARACTER_ONEILL` 精确对上** ——
这不是巧合，是解码正确的证据。

## 后果

**序章地图上永远没有敌人** —— 因为放敌人的脚本是 `ONeillSpawn`。
所以：

* 光标能选艾莉卡（已验证：`(13,9)`，`unitSelected`）
* 但**没有可攻击的目标**，`可行动` 从 14 变 13 是因为"待机"而不是"交战"
* 因此**永远打不到奥尼尔** -> 胜负条件永远不满足 -> **到不了第 1 章**
