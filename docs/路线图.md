# 路线图 —— 按**链路**推进，不按机制积累

> 2026 年这一轮的自我复盘：进度一直"碎"，原因是**在按"哪个便宜"挑活，
> 而不是按"哪条链路能合上"**。便宜的是数据/解码/规则层（越做越顺），
> 而"用户看得见"的链路（战斗表现、菜单、大地图）每一块都贵，于是一直没动。
>
> 链路是**与**关系：链上任何一环缺了，整条都不通（教学事件就是例子：
> 入队 + 3 个钩子做完，用户依然看不到任何教学对话）。
> 所以从这份文档开始：**完成 = 一条链路 4/4**。

## 口径

每条链路四列，**四列全绿才允许说"完成"**：

| 列 | 含义 |
|---|---|
| 数据 | 表/脚本/素材已经从 `third_party/fireemblem8j` 提取进管线（有正向计数抽查）|
| 规则层 | `lib/core` 里是**纯函数**、有单测、`PORT OF:` 指到源文件行号 |
| 表现层 | `lib/game`/`lib/ui` 真的画出来 / 真的会动 |
| 判据 | 可重复执行：`scenario.sh` 的转储断言、单元测试、或棘轮（写进 `run_all.dart`）|

**进度指标 = 4/4 的链路条数**（不是占位符棘轮的调用点数——那只量表面）。

## 两条基础设施（先做，后面每一步都省时间）

### A. 实时控制通道（已落地，`FE8R_CTL=<port>`）

```bash
FE8R_CTL=41999 build/macos/.../fe8r &          # 起游戏（只绑 127.0.0.1）
dart run tools/verify/ctl.dart '{"cmd":"state"}' --get titleFlow.screen
dart run tools/verify/ctl.dart '{"cmd":"press","keys":["confirm"]}'
dart run tools/verify/ctl.dart '{"cmd":"script","seq":"down,wait,confirm"}'
dart run tools/verify/ctl.dart '{"cmd":"quit"}'
```

* `state` → `dumpState()` 全量；`--get` 支持点路径
* `press` → **同一帧内**注入（实测：多键会被同帧合并 ⇒ 多键请用 `script`，它带 60ms 间隔）
* `script` → 复用 `runScript`（支持 `wait`）
* 默认端口 **41999**：⚠️ 别用 19387（那是 DSH Web GUI 的端口，会回 `HTTP/1.1 400`）
* 还没做：**确定性的单帧步进**（`step N frames`）—— 需要给 Flame 一个手动时钟；
  有了它才能把"跑 60 秒再赌一次"换成可重复的逐步推进

### B. 覆盖率账本（✅ 已落地）+ 批量搬运（待做）

用户的判断是对的：**确定的、重复性的先批量做完**，别依赖到一个做一个。
但要先有"做完了"的定义，否则又会变成假进度。所以：

**现状（`docs/覆盖率.md` 自动生成，棘轮已进门禁）**：

| | 总数 | 已见 | 未见/未提取 |
|---|---|---|---|
| 规则层 TU（`src/*.c`）| 6213 | 89 | **6124** |
| 数据目录（`src/data/*`、`graphics/*`、`banim/*`）| 1319 | 34 | **1285** |

* 规则层口径：`src/*.c` 有没有出现在 `lib/**` 的 `PORT OF:` 里 —
  ⚠️ **"未见引用" ≠ "没做"**（可能是数据表/死代码/被别的文件顺带覆盖）。
* 数据目录口径：目录名有没有在提取器源码里出现 —— **弱判据**，
  两个方向都可能偏（递归 glob 覆盖的目录不会提到目录名 ⇒ 高估待办；
  短名字满天飞 ⇒ 低估待办）。所以表头写"未见提及"，不写"未提取"。
* 两张都是**只许降**的棘轮：`dart run tools/verify/coverage_report.dart --check`
  进 L0；`--update` 收紧基线；`--selftest` 证明它会红（清空 PORT OF 后 6124 → 6213）。

下面是原来的做法说明（保留）：

1. `tools/verify/coverage_report.dart`：自动生成 `docs/覆盖率.md` ——

2. 批量顺序（每批都要说清"会被哪条链路用到"，否则就是搬了没人用）：
   * **数据批**：所有 carve 出来的表/符号进管线（含现在 42 个"有名字没内容"的事件组、
